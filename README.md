# Vinay Barman — Cybersecurity Portfolio

A responsive personal portfolio built with React and Vite. It presents Vinay's cybersecurity learning profile, skills, personal projects, education, certification, and contact links.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173/`.

## Build

```bash
npm run build
npm run preview
```

## Publish with GitHub Pages

1. Push this repository to GitHub when you are ready to publish it.
2. In the repository, open **Settings → Pages** and set the source to **GitHub Actions**.
3. Add a workflow that installs dependencies, runs `npm run build`, and publishes the generated `dist/` directory using GitHub's Pages artifact actions.
4. After the workflow completes, use the published URL shown under **Settings → Pages**.

For a project site served from `https://<username>.github.io/<repository>/`, set Vite's `base` option in `vite.config.js` to `/<repository>/` before building. A user or organization site at `https://<username>.github.io/` uses `/`.
